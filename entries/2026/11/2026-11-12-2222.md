TIL about the concept of Physical Unclonable Functions or PUFs for short.

The idea being that instead of storing a key somewhere to decrypt something (e.g. your firmware), you just use undefined but deterministic behavior of the hardware you're running on as a key.
Utilizing the fact that all silicon is slightly different while still in-spec and using the difference for something.

For example, apparently, SRAM has cells and these cells are either 1 or 0, but, when powering up, each cell has a different tendency as what it will show up as.
Once you write them, it doesn't matter, but the uninitialized state apparently can be fairly deterministic and with that usable as a key (with some post-processing, apparently).
